# C4 Level 4 – Code Level Overview

- `GameState` – Stores the current state of the game.
- `CoordinatorAgent` – Coordinates the decisions of different agents.
- `StrategyAgent` – Develops the overall game strategy.
- `ActionAgent` – Selects the appropriate game action.
- `GameEngine` – Executes the selected action and updates the game state.
- `selectAction()` – Selects the final action to execute.
